A Hive engine with a learned evaluation: nokamute's rules and search framework (by Eric
Roshan-Eisner, MIT) with tocandira's evaluation and search additions. It speaks the
Universal Hive Protocol; in MzingaViewer, set the Engine to the binary.

## Strength

tocandira (nokamute's rules and search framework, with the tocandira evaluation and search
additions) vs nokamute 1.0.3, equal time per move, 1 s per move, one thread each, this
release's binary with its defaults: **97.8% [96.5, 98.6], +660 [+579, +742]** over 800
games (W779 D7 L14, no forfeits, 2026-10-27). The scale saturates there: the +93 of this
net over the previous best does not show against 1.0.3, so later progress is measured
against our own previous release.

How it got there, in timed matches at 1 s per move: the first net +34 over nokamute 1.0.3
(2026-10-14), `l/lam09-s0` +650 (2026-10-20), then +104 and +93 over our own previous
bests. Records in
[docs/benchmarks.md](https://github.com/abstratovcm/tocandira/blob/v1.0.0/docs/benchmarks.md).

## What is in it

- The net `o-g2b-warm-s0.bin` (sha1 0795fb4c40558b038195972bd4ac7b9acf9a8419, also attached):
  two perspective accumulators of 128, layers of 16, 12 strategy scalars, trained on
  14.8M self play positions labeled by the searches of an earlier net, `l/lam09-s0`
  (generation 2,
  [docs/pipeline.md](https://github.com/abstratovcm/tocandira/blob/v1.0.0/docs/pipeline.md)).
- Search additions, each kept after a timed match: null move pruning, late move reductions,
  partial iterations, killer moves, reverse futility pruning (margin 124, scaled to the
  net's output spread).
- One thread by default, the configuration every result above was measured in. With
  `NumThreads` above 1 the engine uses nokamute's parallel search, which has null move
  pruning but not the other four additions; its strength is not measured.

## Use

- Linux: `tar xzf tocandira_linux_amd64.tar.gz`, then `./tocandira` (UHP on stdin).
- Windows: `tocandira.exe` from `tocandira_win64.zip`.
- AVX2 is used when the CPU has it, a portable path otherwise.
- From source: `git clone --recursive https://github.com/abstratovcm/tocandira`, then
  `scripts/build_release.sh`.

Speed and move generation are nokamute's; tocandira claims neither.
